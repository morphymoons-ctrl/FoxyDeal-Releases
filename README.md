# Лисяча Угода / Foxy Deal

Настільна гра про бізнес з українськими брендами для Windows: 2–5 гравців по мережі, на великій дошці — до 8. Можна грати й з ботами.

**Встановити:** завантажте [FoxyDeal-Install.exe](https://github.com/morphymoons-ctrl/FoxyDeal-Releases/releases/latest/download/FoxyDeal-Install.exe), запустіть і оберіть папку. Далі гра оновлюється сама.

---

A property-trading board game with Ukrainian brands for Windows: 2–5 players over the network, up to 8 on the big board. You can also play against bots.

**Install:** download [FoxyDeal-Install.exe](https://github.com/morphymoons-ctrl/FoxyDeal-Releases/releases/latest/download/FoxyDeal-Install.exe), run it and pick a folder. The game updates itself after that.
